# Animation Baker 1.0 사용자 가이드

Animation Baker는 Unreal Editor 안에서 **참고 영상이나 기존 애니메이션을 가져와 → 내 캐릭터에 적용하고 → 프레임별로 자세를 다듬어 → 애니메이션 에셋·몽타주·SpriteBaker 프로젝트로 내보내는** 편집 도구입니다. 에디터 전용 플러그인이며 게임 런타임에는 포함되지 않습니다.

English: see `UserGuide_EN.md`.

---

## 1. 요구 사항

| 항목 | 내용 |
|---|---|
| 엔진 | Unreal Engine 5.8 (Win64 Editor). 다른 엔진 버전은 Fab 제품 페이지에 표시된 버전만 지원합니다. |
| OS | Windows 10/11 64비트 |
| 영상 분석 | 최초 1회 인터넷 연결(약 1GB 다운로드), 디스크 여유 2GB 이상 |
| Python | 별도 설치 불필요. 엔진에 포함된 Python 3.11로 독립 환경을 만듭니다. |
| 의존 플러그인 | IK Rig, Full Body IK, Animation Data, Niagara(엔진 기본 포함, 자동 활성화) |

## 2. 설치

1. Fab 라이브러리에서 엔진에 설치하거나, 프로젝트의 `Plugins/AnimationBaker` 폴더에 넣습니다. 엔진과 프로젝트에 중복 설치하지 마세요.
2. **편집 → 플러그인 → Animation Baker**를 켜고 에디터를 다시 시작합니다.
3. **도구 → Animation Baker**로 창을 엽니다.

## 3. 빠른 시작 (5분)

1. 왼쪽 위 **가져오기 → 예제 애니메이션 셋 만들기**: 설치된 엔진의 Third Person 템플릿에서 Manny를 프로젝트로 복사하고 26개 상태(Idle, Walk/Jog 8방향, Jump, Attack 등)가 있는 예제 프로젝트를 만듭니다. 템플릿이 없으면 Launcher에서 *Templates and Feature Packs*를 설치하거나 내 캐릭터·애니메이션을 직접 선택하세요. 예제 자산은 플러그인에 포함되지 않습니다.
2. 왼쪽 상태 트리에서 상태를 고르고, 타임라인에서 프레임을 고른 뒤 **본 트리** 또는 뷰포트의 초록 구를 드래그해 자세를 고칩니다.
3. **프로젝트 저장(Ctrl+S)** 후 **내보내기…**에서 Animation Sequence / Montage / SpriteBaker 프로젝트를 출력합니다. 원본 에셋은 덮어쓰지 않습니다.

## 4. 영상에서 동작 가져오기

### 4.1 영상 엔진 준비 (최초 1회)
상단 **영상 가져오기** 창 → **영상 엔진 준비**. 내려받는 구성 요소와 라이선스를 확인하는 창이 뜹니다. 승인하면 다음을 `%LOCALAPPDATA%\DOCKINI\AnimationBaker\VideoEngine-v3`에 설치합니다.

- Python 패키지(MediaPipe 0.10.21, OpenCV, NumPy, SciPy 등, 버전 고정, 바이너리 휠만 사용)
- MediaPipe Pose Landmarker Heavy 모델 (Apache-2.0, SHA-256 검증)
- FFmpeg 9.0.2 (gyan.dev Windows 빌드, GPL, SHA-256 검증)

엔진 Python이나 프로젝트 파일은 수정하지 않습니다. 분석은 이 PC에서만 실행되며 영상은 업로드되지 않습니다. 다른 Python 3.10~3.12를 쓰려면 입력란에 경로를 지정하세요.

### 4.2 분석
1. **영상 또는 CelMotion 프로젝트 선택…** — mp4/mov/mkv/avi/webm/m4v. **이 PC에 저장된 파일만** 지원하며, 직접 촬영했거나 사용할 권리가 있는 영상만 사용하세요.
2. 미리보기에서 **대상 인물의 전신**을 드래그로 둘러쌉니다. **선택 인물 추적**이 기본으로 켜져 있습니다.
3. 시작·끝 프레임(최대 30초)을 정하고 **분석 후 새 상태에 적용**.
4. 군무·교차 이동으로 대상이 바뀌면 그 프레임으로 이동해 영역을 다시 그려 **추적 보정점**을 추가합니다.

결과는 30fps **제자리(in-place)** 동작입니다. 같은 영상·영역을 다시 분석하면 관절 분석 캐시를 재사용합니다. 데스크톱 CPU 기준으로 영상 1프레임에 약 1~2초가 걸립니다(30fps 10초 구간 약 5~10분). 처음 여는 긴 영상은 편집용 프록시와 미리보기·인물 인덱스를 만드는 시간이 추가됩니다. 이후 미리보기 이동은 바로 표시되고, 추적 보정점을 추가해 다시 분석하면 저장된 인물 후보로 추적만 다시 하고 영역이 바뀐 프레임만 새로 분석합니다.

**대상 추적(1.0)**: 상의와 하의(허벅지)의 색·밝기, 첫 프레임에서 기억한 외형, 위치 연속성을 함께 사용합니다. 겹친 순간에 옷차림이 다른 사람으로 넘어가지 않고, 그 프레임을 **대상 인물 확인 필요**로 남깁니다. 분석 후 안내에 그 수와 첫 프레임이 표시되며 **문제가 감지된 프레임 보기**로 이동해 보정점을 추가할 수 있습니다. 같은 옷을 입은 사람끼리 교차하는 경우는 보정점이 필요할 수 있습니다.

**대상 확인**: 추적은 됐지만 몸통 위치가 1~2프레임 동안 크게 튀었다가 돌아온 프레임은 다른 사람이 잠깐 선택됐을 가능성이 있어 따로 **대상 확인 N프레임**으로 표시됩니다. **다음 대상 확인 프레임 보기**로 차례로 확인하고, 다른 사람이면 그 프레임에 보정점을 추가해 다시 분석하세요. 거의 같은 자리에 선 사람으로 바뀐 경우는 감지하지 못합니다.

**관절 고정**: 분석 후 미리보기에 대상의 어깨·팔꿈치·손목·골반·무릎·발목 점이 표시됩니다. 틀린 점을 끌어 옮기면 그 프레임의 **관절 고정**이 되고(주황색, 몸통 네 점도 함께 고정), 다시 분석하면 그 프레임은 고정한 위치를 그대로 쓰고 대상 인물도 그 점에 맞는 사람으로 정합니다. 앞뒤 6프레임은 확신이 낮은 관절만 조금 따라오고, 나머지 프레임은 매 프레임 새로 검출합니다. **다음 관절 한계 프레임 보기**로 관절 한계 밖으로 표시된 프레임부터 확인하세요. 몇 프레임만 고정하는 것이 좋습니다.

**장면 전환 검사(1.0)**: 선택한 구간 안에서 장면이 바뀌면(편집 컷·전환 효과) 분석 전에 중단하고 해당 프레임을 알려 줍니다. 한 장면 안에서 구간을 다시 선택하세요.

**여러 구간 한 번에 분석**: 긴 영상 하나에 동작이 여러 개 있으면 영상 창의 **여러 구간 한 번에 분석**을 펼칩니다.
- **현재 구간을 목록에 추가**: 위에서 고른 시작·끝 프레임과 전신 영역을 목록에 넣습니다. 같은 구간은 두 번 들어가지 않습니다.
- **장면 전환에서 나누기**: 편집 컷마다 영상 전체를 자동으로 나눕니다.
- **자막이 바뀌는 곳에서 나누기**: 기술 이름처럼 화면의 자막이 바뀔 때마다 나눕니다. 미리보기에서 자막 글자를 감싸는 상자를 그리고 **현재 영역을 자막 영역으로**를 누른 뒤, 인물의 전신 영역을 다시 그리고 누르세요. 자막이 없는 구간은 빠지고, 30초보다 긴 구간은 나눠집니다.
- 목록에서 이름을 고치고(이름이 상태 이름이 됩니다) **목록 모두 분석**을 누르면 구간마다 새 상태가 하나씩 생깁니다. 실패한 구간이 있어도 나머지는 계속 분석하고, 끝나면 완료·실패 수와 구간별 신뢰도를 보여 줍니다. 실패한 구간은 **보기**로 열어 범위나 영역을 고친 뒤 **갱신**하고 다시 분석하세요.

### 4.3 결과 검토와 보정
- 타임라인 본 행의 **분홍 선**은 신뢰도 45% 미만인 구간입니다. **다음 보정 프레임 →**으로 해당 프레임·본을 바로 선택합니다.
- 1.0부터 **바닥 위를 미끄러지는 발**도 분홍 구간으로 표시됩니다(아래 4.4).
- **관절 한계 밖 자세**(무릎·팔꿈치가 반대로 꺾임, 불가능한 고관절·어깨·척추·목 각도)도 분홍 구간으로 표시되고, 결과 안내에 관절별 개수와 첫 프레임이 나옵니다. 대부분 영상 깊이 오차에서 생기므로 측면 카메라에서 확인해 수정하세요. 분석 옵션 **관절 한계 밖 자세 자동 보정**(실험, 기본 꺼짐)을 켜면 발목·손목 위치는 그대로 두고 무릎·팔꿈치 굽는 방향과 머리 방향을 범위 안으로 돌립니다. GPU 고품질 3D를 쓰면 위반이 크게 줄어듭니다.
- 신뢰도는 정확도의 실측치가 아닙니다. 보간·추정된 구간은 원본 영상과 비교해 직접 수정하세요.

### 4.4 발 접지
- **발 접지 보정**(기본 켜짐)은 영상에서 감지한 접촉 동안 발의 실제 신발 바닥을 바닥 높이에 맞추고 수평 위치를 고정합니다. 다리가 닿지 않으면 본 길이를 늘리지 않고 골반을 보정합니다.
- 1.0 접지(v2): 영상 감지기가 놓친 접촉도 **캐릭터 메시의 발바닥이 바닥에서 2cm 이내이고 초속 1.5m 미만으로 0.12초 이상 머무르면** 접지로 추론합니다. 점프처럼 발이 떠 있는 구간은 추론하지 않습니다.
- 잠금 없이 바닥에서 빠르게 미끄러지는 발 프레임은 수정하지 않고 **검토 대상**으로 표시합니다.
- 접지 v3: 발을 맞추다가 무릎이 옆이나 뒤로 꺾이면, 무릎을 골반→발 축 둘레로 가장 적게 돌려 다리 가동 범위 안으로 넣습니다. 발 위치와 무릎 굽힘 각도는 바뀌지 않습니다. 이전에 저장한 상태는 v2를 유지합니다.
- 1.0 이전에 저장한 상태는 결과가 바뀌지 않도록 기존 접지 방식을 유지합니다. 같은 영상을 다시 가져오면 새 방식이 적용됩니다.
- **바닥 높이 (cm)**로 바닥을 조절하고, 체크를 끄면 원본 동작과 비교할 수 있습니다.

### 4.5 CelMotion 포즈
`.celmotion` v1 프로젝트 또는 CelMotion 형식 `.npz`를 읽습니다. 영상 크기 정보가 없는 NPZ는 **골반 높이 고정**을 사용합니다.

### 4.6 GPU 고품질 3D (선택 · 실험)
NVIDIA GPU(메모리 6GB 이상)가 있으면 3D 자세를 **SAM 3D Body**(Meta)로 추정할 수 있습니다. 2D 추적, 대상 확인, 검토 표시, 발 접지는 기본 엔진과 같고 3D 관절만 바뀝니다.

- **준비:** 영상 창 아래 **GPU 고품질 엔진 준비 (선택)** → 동의 창 확인. PyTorch(CUDA 12.4)와 모델(약 7.5GB)을 `VideoEngine-v3\gpu`에 설치합니다. 기본 영상 엔진은 건드리지 않습니다.
- **사용:** 준비가 끝나면 분석 옵션에 **GPU 고품질 3D**가 나타납니다. 켜고 분석하면 30초 구간 기준 약 3분이 더 걸립니다(RTX 3090 측정).
- **효과(내부 측정):** 넓게 선 자세가 측면에서 무릎을 꿇은 모양으로 나오던 문제, 손발 떨림, 발 미끄러짐이 줄었습니다. 빠른 회전 구간은 팔다리 방향이 기본 엔진보다 나쁠 수 있습니다.
- **실패 시:** GPU 메모리 부족, 드라이버 문제 등으로 실패하면 기본 3D로 계속 진행하고, 결과 안내에 이유를 표시합니다.
- **라이선스:** SAM 3D Body는 SAM License를 따르며 군사·전쟁, 무기, 핵, 첩보 용도 등을 금지합니다. 자세한 내용은 `Docs/THIRD_PARTY.md`를 확인하세요.

## 5. 자세 편집

- **초록 구 드래그 = 이동**, **Shift+드래그 = 화면 깊이 방향 이동**. 이동 화살표(W)와 회전 링(E)이 함께 표시됩니다.
- 구 클릭/우클릭 → 수치 도구 창: XYZ 위치·회전, **위치 고정 / 회전 고정**, 허용치(0~100), 축별 회전·이동 리미트.
- 수정은 현재 프레임 중심으로 앞뒤 프레임에 부드럽게(quintic) 퍼집니다. 영향 범위는 도구 창에서 바꾸거나 **현재 프레임만**을 선택합니다.
- 작은 손목 이동은 팔 안에서 먼저 해결하고, 부족하면 어깨·몸통이 점진적으로 참여합니다. **이 부위만 조절**로 몸통 연동을 끕니다.
- 실행취소/다시 실행: Ctrl+Z / Ctrl+Y(또는 Ctrl+Shift+Z). 드래그 한 번이 기록 한 번이며 드래그 중 Esc는 취소입니다.
- 탐색: 프레임 숫자 입력, ◀▶ 한 프레임, Page Up/Down = 이전/다음 수정, Home/End, Space = 재생/정지.
- 오른쪽 **카메라 뷰**(좌·우·후면)는 더블클릭으로 독립 창이 됩니다.
- **잔상**(이전/다음 프레임 메시)의 구를 직접 드래그하면 해당 이웃 프레임만 수정합니다.
- 타임라인 열 삽입·삭제·복사·복제는 노티파이·커브·동기화 마커 타이밍을 함께 보정합니다.
- **블렌딩 레이어**: 다른 애니메이션 구간을 강도·페이드·본 마스크로 섞어 굽습니다.
- **소켓**: 본 우클릭 → 소켓 생성. 작업용 부착점이며 원본 Skeleton은 바꾸지 않습니다.

## 6. 애니메이션 셋 프로젝트

**그룹(캐릭터) → 모션 셋 → 상태 → 변형** 구조를 하나의 프로젝트 에셋에 저장합니다. 상태마다 루프·루트 잠금·출력 구간을 설정하고, 분기마다 편집과 실행취소 기록이 따로 유지됩니다. 트리 아래 ↶/↷는 구조 변경 실행취소입니다. 약 2초 간격의 복구 사본은 `Saved/AnimationBaker/ProjectRecovery`에 저장되며 정식 백업을 대신하지 않습니다.

- 왼쪽 위 탭에서 **가져오기 · 연계 작업 · 콘텐츠 · 블렌딩**을 바꿔 가며 쓰고, 셋 트리는 그 아래에 항상 보입니다.
- **+상태 / +세트 / +그룹 / +변형**을 누르면 새 이름 칸에 바로 입력할 수 있습니다(기존 이름이 선택된 상태). 트리 항목을 더블클릭해도 이름을 바꿀 수 있습니다.
- 아직 동작이 없고 기본 이름(Idle, State)인 상태에 첫 동작을 넣으면 상태 이름이 동작 이름으로 바뀝니다. 예: MM_Attack_01 → Attack_01. 같은 이름이 이미 있으면 바꾸지 않습니다.
- 저장하지 않은 셋이 있으면 탭을 닫거나 에디터를 끌 때 저장할지 묻습니다.

## 7. 내보내기

저장한 프로젝트를 고치지 않은 채 내보내면, 내보내기가 기록하는 출력 설정과 몽타주 연결도 프로젝트에 함께 저장됩니다. 그래서 내보낸 직후 창이나 에디터를 닫아도 저장 여부를 묻지 않습니다. 저장하지 않은 편집이 있으면 대신 저장하지 않습니다.

**내보내기…** 창에서 범위(전체/그룹/셋/상태/변형), 출력 종류(Animation Sequence, 상태별 Montage, SpriteBaker 프로젝트), 이름 규칙(`{project} {group} {motion} {state} {variant}`), In-place / 루트 모션, 노티파이·커브 포함 여부, Montage 슬롯·블렌드를 정합니다. 충돌 시 새 번호를 붙이며 원본은 덮어쓰지 않습니다.

**SpriteBaker 연동**(별도 제품): AnimationBridge v2를 지원하는 SpriteBaker가 설치·활성화되어 있으면 새 SpriteBaker 프로젝트를 만들어 엽니다. 없으면 `Saved/AnimationBaker/Exports`에 JSON과 에셋 경로를 남깁니다.

## 9. 한계 (구매 전 확인)

- 영상 모캡은 **단안 카메라 추정**입니다. 깊이·팔다리 비틀림·가려진 신체·화면 밖 팔다리는 추정이며 수동 보정이 필요할 수 있습니다.
- 사용 모델(MediaPipe BlazePose GHUM 3D)은 **한 화면 한 사람, 카메라에서 약 4m 이내, 머리가 보이는 영상**을 대상으로 설계되었습니다. 여러 사람이 있는 영상은 대상 추적과 보정점으로 지원하지만 품질이 낮아질 수 있습니다.
- 출력은 **제자리 동작**입니다. 수평 이동 경로, 손가락·발가락 개별 관절, 임의의 카메라 움직임 복원은 지원하지 않습니다. 카메라 보정은 작은 확대·이동만 완화합니다.
- 제자리 출력에서는 실제로 이동하며 체중을 옮기는 동작의 발이 미끄러질 수 있습니다. 이런 프레임은 검토 대상으로 표시됩니다.
- 한 번에 최대 30초, 30fps 출력.
- UI 언어는 영어(기본)와 한국어입니다. 상단 툴바 오른쪽 언어 메뉴에서 **한국어**를 고르면 Animation Baker 창이 한국어로 다시 열립니다.

## 10. 문제 해결

| 증상 | 해결 |
|---|---|
| "‘영상 엔진 준비’를 먼저 눌러 주세요" | 4.1을 실행하세요. 엔진을 다른 버전으로 바꾼 뒤에도 다시 준비하면 환경을 재구성합니다. |
| 준비 실패: 패키지 설치 | 인터넷/프록시를 확인하고 작업 폴더의 `setup.log`를 확인하세요. 회사 방화벽은 pypi.org, files.pythonhosted.org, storage.googleapis.com, github.com 접근이 필요합니다. |
| FFmpeg 무결성 실패 | 다운로드가 손상되었거나 차단되었습니다. 다시 준비하세요. 사내 미러가 필요하면 환경 변수 `ANIMATIONBAKER_FFMPEG_DIR`에 ffmpeg.exe/ffprobe.exe 폴더를 지정할 수 있습니다. |
| 대상이 다른 사람으로 바뀜 | 그 프레임에서 영역을 다시 그려 추적 보정점을 추가하세요. |
| 발 접지 목표 오차 경고로 굽기 실패 | 바닥 높이를 조정하거나 접지 보정을 끄고 자세를 확인하세요. |
| 캐시가 커짐 | 영상 창의 **영상 엔진 준비** 영역에 프록시·인덱스, 분석 캐시, 작업 폴더 크기가 표시됩니다. **정리**는 열려 있는 영상만 남기고 지우며, **캐시 상한**(기본 20GB)을 넘으면 오래 쓰지 않은 영상부터 자동으로 지웁니다. 7일 지난 작업 폴더도 자동 삭제됩니다. `%LOCALAPPDATA%\DOCKINI\AnimationBaker\VideoEngine-v3\cache`를 직접 지워도 됩니다(다음에 다시 생성). |
| 런타임 폴더 변경 | 환경 변수 `ANIMATIONBAKER_RUNTIME_ROOT`로 위치를 지정할 수 있습니다. |
